# Week 7 – TaskFlow To-Do List

IYF Wecan Academy – Season 12

## About the Project

This is my Week 7 project. I created a To-Do List application called TaskFlow using HTML, CSS, and JavaScript.

The application helps users organise their daily tasks, track completed work, and manage their activities.

I also included a simple Shopping Cart demonstration to practise JavaScript modules and application logic.

## Features

### TaskFlow To-Do List

- Add new tasks.
- Mark tasks as completed.
- Delete tasks.
- Filter tasks by All, Active, and Completed.
- Clear completed tasks.
- Save tasks using Local Storage.
- Display the number of remaining tasks.

### Shopping Cart

- Display products.
- Add products to the cart.
- Manage cart items.
- Calculate the total price.
- Complete a demo checkout without making a real payment.
